# Lost Mine of Phandelver — Tóm tắt nghiên cứu

> **Nguồn**: Tổng hợp từ D&D Beyond (TOC), AnyFlip preview (pages 1-22 chi tiết),
> Forgotten Realms Wiki, Reddit r/DMAcademy, RPG StackExchange, EN World, DM guide blogs.
> **Mục đích**: Benchmark medium campaign để đánh giá 144mb budget.
> **Hệ thống**: D&D 5e Starter Set · Level 1-4 · ~50 giờ / 12-15 session

## 2. Locations (13 locations chính)

### Towns/Hubs
- **Neverwinter** — coastal city, điểm xuất phát
- **Phandalin** — frontier town hub, built trên older ruins

### Dungeons (5 dungeon chính)
1. **Cragmaw Hideout** — cave system, goblin base (Part 1, 8 areas)
2. **Redbrand Hideout** — dưới Tresendar Manor (Part 2, 8 areas)
3. **Cragmaw Castle** — stronghold của King Grol (Part 3)
4. **Wave Echo Cave** — final dungeon, lost mine + Forge of Spells (Part 4, ~16 areas)
5. **Ruins of Thundertree** — abandoned town, undead + dragon

### Wilderness locations (Part 3 sandbox)
- **Triboar Trail** — road, random encounters
- **Conyberry** + **Agatha's Lair** — banshee lair
- **Old Owl Well** — ancient watchtower ruins, undead
- **Wyvern Tor** — orc raiders

## 8. Asset manifest cho 144mb (đếm thực từ module)

So sánh ước lượng trước vs đếm thực từ LMoP:

| Hạng mục | LMoP thực tế | Ước lượng trước | Chênh |
|---|---|---|---|
| **NPC có tên/dialogue** | ~20 | 40 | LMoP = 50% |
| **Dungeon maps** | 5 (Cragmaw Hideout, Redbrand, Cragmaw Castle, Wave Echo, Thundertree) | 8 biomes | LMoP = 63% |
| **Wilderness/town maps** | 3 (Phandalin, Triboar, wilderness) | — | |
| **Monster unique stat blocks** | ~25 | 50 | LMoP = 50% |
| **Magic items** | ~12 | 80 | LMoP = 15% |
| **Tile types cần** | ~30 (cave, town, crypt, castle, ruins, forest) | 116 | LMoP = 26% |
| **Boss sprites** | 4 (Klarg, King Grol, Nezznar, Venomfang) | — | |
| **Cutscene art** | 4 (chapter intros) | 15 | LMoP = 27% |

**→ LMoP là ~30-50% campaign medium "đầy đủ"** — hoàn toàn khả thi cho 1.44MB.
